# Vocelune Backend (Workspace)

Theo đặc tả kiến trúc **EVLP-SRS-001**:
- **Framework:** NestJS (TypeScript, Modular Monolith)
- **Database:** PostgreSQL 16+ (Prisma / Drizzle ORM)
- **Queue & Cache:** Redis + BullMQ
- **Object Storage:** Cloudflare R2 (presigned URLs)
- **Scheduler Core:** FSRS Engine Adapter
