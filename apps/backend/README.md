# Vocelune Backend

NestJS + PostgreSQL 16 + Prisma 6.19, Redis/BullMQ worker, FSRS-6 (`ts-fsrs` 5.4.2).

Từ thư mục gốc:

```bash
npm install
npm run setup
npm run dev
```

Tài liệu: [API và vận hành](../../docs/backend.md). Schema: [schema.prisma](prisma/schema.prisma). OpenAPI: [localhost:4000/api/docs](http://localhost:4000/api/docs).
